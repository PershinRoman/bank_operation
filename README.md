Главная страница
Требования:

Реализовать функцию, которая принимает на вход строку с датой и временем в формате YYYY-MM-DD HH:MM:SS и возвращает JSON-ответ со следующими данными:

Приветствие в зависимости от времени суток:

Доброе утро (с 5:00 до 12:00)
Добрый день (с 12:00 до 17:00)
Добрый вечер (с 17:00 до 23:00)
Доброй ночи (с 23:00 до 5:00)
По каждой карте:

Последние 4 цифры карты.
Общая сумма расходов.
Кешбэк (1 рубль на каждые 100 рублей расходов).
Топ-5 транзакций по сумме платежа.

Курс валют.

Стоимость акций из S&P500.

Шаги для реализации:

1. Импортируйте необходимые библиотеки
2. Настройте логирование
3. Функция для определения приветствия
4. Функция для обработки данных по картам
5. Функция для получения топ-5 транзакций
6. Функции для получения курса валют и стоимости акций
7. Основная функция

# Отчёты
### 1. Траты по категории
Требования:

Функция принимает на вход датафрейм с транзакциями, название категории и опциональную дату. Возвращает траты по заданной категории за последние три месяца от переданной даты.

Шаги для реализации:

1. Функция расчёта трат по категории
2. Декоратор для записи в файл

### 2. Траты по дням недели

1. Функция расчёта трат по дням недели
